Hapa Admin

Overview

What visitors see on homesupport.co.ke right now. Changes here go live within about a minute, with no code push. Every change is logged and can be undone.

Emergency pause

One button that switches off every optional page and puts up a "paused" notice. Your own notice and page settings are saved and come back when you resume. Emergency numbers stay available.

How fresh is the data?

Dates are read from the live data. "Not available" means we could not read it, not that it is up to date.

Loading…

New incidents are looked for automatically four times a day. This asks for an extra check; it starts within the hour and only publishes what two sources confirm.

Red alert strip

A strong red strip across the top of every page, for something urgent. It needs an end time so it can never be left on by mistake. Times are East Africa Time.
